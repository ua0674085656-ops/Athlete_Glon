# Athlete Glon

Приложение для силовых тренировок. Android, весь интерфейс и логика — в одном
HTML-файле внутри WebView. Не публикуется в магазинах, ставится вручную.

## Что умеет

- Генерирует программу под цели спортсмена, распределяет объём по дням недели
- Считает прогрессию веса и повторов по RIR
- Оценивает восстановление мышц и готовность по утреннему опросу
- Ужимает тренировку под доступное время, не урезая приоритеты
- Строит путь по зонам тела: визуальное желание → сантиметры, килограммы, сроки
- Считает калории и макронутриенты
- Два языка: русский и украинский

## Сборка

APK собирается автоматически через GitHub Actions после каждого коммита в `main`.

1. Вкладка **Actions** в репозитории.
2. Верхний зелёный запуск → **Artifacts** → скачать `apk`.

## Установка на телефон

1. Скачать APK.
2. Разрешить установку из неизвестных источников.
3. Установить.
4. При первом запуске разрешить уведомления — это таймер отдыха.
